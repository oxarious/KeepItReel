# KeepItReel website

Reading this as a consumer extension website for everyday Chrome users, with a calm, approachable character. Use the established pine identity and a useful interactive demonstration as the central visual.

Design variance 5, motion intensity 2, visual density 3. A predominantly light page with warm paper, forest ink, a muted sage demonstration backdrop and restrained ochre/red warning accents. Whole-page dark theme, not alternating inverted sections. Self-host Atkinson Hyperlegible Next. Large left-aligned headlines, generous margins, flat sections, modest rounded controls. No gradients, decorative charts, inflated metrics, invented reviews, infinite motion or AI-authorship guarantees.

The existing Thinker monkey is the only custom icon. Letter marks and native controls replace platform logos. Illustration is a functional, explicitly fictional browser demonstration, never a fake product screenshot. The site does not scan visitors or send demo data.

Reference tooling: Clinic-pro/DESIGN-TOOLKIT.md and tools/design-toolkit. Reviewed Broog Effects catalogue; no animation-library runtime required for this restrained design. Original styles and interactions. No customer-project files or hosting identities copied.

Public launch: new release in early development, no beta signup, no paid feature tiers. Installation and contribution links must resolve to owner-configured destinations. Until then explain availability in an honest dialog. Feedback can always be copied; email action requires a configured public address. Never fabricate successful submission.
