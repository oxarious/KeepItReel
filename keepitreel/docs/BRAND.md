# KeepItReel branding

The selected logo is The Thinker: a thoughtful chimp emerging above an open
human profile, both facing right. The product name is KeepItReel.

The application logo lives in `public/brand/keepitreel-logo.svg`. It contains
vector paths, including the lettering. It has no font or external dependency.
The rounded browser icons in `public/icon/` are PNG exports of the compact
vector variant at the sizes required by the manifest.

The complete logo kit is delivered separately as `keepitreel-logo-kit.zip`.
It contains horizontal and stacked logos, the emblem, the wordmark, pine/white/
black variants, transparent PNGs and browser icons. The SVGs are the masters.

Pine is #163C30 and pale green is #CEE8AE. Keep the proportions and clear space.
Use the detailed mark for larger applications and the compact variant for small
icons. Do not add a slogan to the logo.

UI copy should name the feature, report its state, explain a limit or tell the
user what an action does. Avoid decorative slogans, motivational copy and
duplicate headings that add no information.

The hair tufts are part of the selected character. Preserve them in the detailed
and compact variants; do not replace the scalp with a smooth arc. Use the white
logo on the dark pine interface.
